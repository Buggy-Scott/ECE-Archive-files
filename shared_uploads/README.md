## How to Upload Files

### Instructions
1. Fork this repository
2. Add your files inside the `shared_uploads` folder
3. **Name files with the course code prefix** (see format below)
4. Create a Pull Request
5. The workflow will automatically organize your files into the correct course folder

### File Naming Format
Files must follow this naming pattern to be automatically organized:

```
[COURSE-CODE]-[Description].[extension]
```

### Examples
- `2201-Lab3-Report.pdf` → placed in `ECE 2201-2202 - Circuits Analysis and LAB/`
- `3317-EM-Notes.docx` → placed in `ECE 3317 EM Waves/`
- `3337-Signal-Processing.pdf` → placed in `ECE 3337 - Signals and Systems/`
- `3340-Numerical-Methods.py` → placed in `ECE 3340 Numerical Methods/`
- `3355-Circuit-Design.txt` → placed in `ECE 3355-3155 Electronics and Lab/`
- `3436-Assembly-Code.asm` → placed in `ECE 3436 MicroProcessing/`
- `3441-Logic-Design.vhd` → placed in `ECE 3441 - DLD/`

### Supported Course Codes
- `2201` or `2202` → ECE 2201-2202 - Circuits Analysis and LAB
- `3317` → ECE 3317 EM Waves
- `3337` → ECE 3337 - Signals and Systems
- `3340` → ECE 3340 Numerical Methods
- `3355` or `3155` → ECE 3355-3155 Electronics and Lab
- `3436` → ECE 3436 MicroProcessing
- `3441` → ECE 3441 - DLD

---

**Important Notes:**
- Please do not modify files outside the `shared_uploads` folder
- Files will be automatically moved to their course folders after merge
- Keep files named clearly so others can find them easily
